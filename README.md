# Workout Log

広告なしのシンプルな筋トレ記録アプリ。GitHub Pages で動く静的な Web アプリ（PWA）です。

- 種目ごとに 重量 × 回数 のセットを記録
- 前回の記録を表示、自己ベスト（PR）を表示
- 休憩タイマー
- 履歴・種目ごとのグラフ（最大重量 / 推定1RM / ボリューム）
- JSON でバックアップ・復元

## データの保存場所

記録は **使っている端末のブラウザ内（IndexedDB）だけ** に保存されます。サーバーには送られず、このリポジトリにも含まれません。
機種変更などに備えて、設定 → バックアップ →「書き出す」でときどき保存してください。

## iPhone で使う

1. Safari で公開 URL を開く
2. 共有ボタン →「ホーム画面に追加」

ホーム画面から開くとアプリのように全画面で動き、オフラインでも使えます。
（Safari のタブで使い続けると、しばらく開かなかったときにデータが消されることがあるので、ホーム画面からの利用がおすすめです）
